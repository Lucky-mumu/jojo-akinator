### 💡 ジョジョ・アキネイター

『ジョジョの奇妙な冒険』のキャラクターに特化した、アキネイター風の推測Webアプリケーションです。
キャラクターを思い浮かべて質問に答えていくことで、そのキャラクターを推測してくれます。

#### 📌 開発の背景
既存の汎用的な推測システムとは異なり、特定作品にフォーカスしています。単に質問に答えるだけでなく、ユーザーの回答データをバックエンドに集計し、**利用者が増えるほど推測精度が動的に向上していく学習型システム**を目指して設計しました。

#### 🛠️ 技術スタック
- **フロントエンド:** HTML / JavaScript
- **推測ロジック:** 確率モデル（ベイズ推定ベースの絞り込みアルゴリズム）
- **バックエンド・データベース:** Supabase（ユーザーの解答・選択データのリアルタイム集計と永続化）
- 設計にあたって生成AIのclaudeを利用しています。
